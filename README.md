# Pythagorean Tree Fractal Angle Morphing Art

Renders a Pythagorean tree fractal on HTML5 canvas by recursively drawing squares with right-triangle branching; left-angle, right-angle (0–90°), and depth (2–12) sliders control the form. Features an autumn-to-spring color gradient from deep brown trunk to spring green leaves, with a Play button to animate a continuous angle sweep and PNG export.
